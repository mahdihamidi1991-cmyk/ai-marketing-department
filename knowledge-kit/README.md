# Knowledge kit

These are editable English templates, not facts about an existing business. Fill them with approved evidence, keep source dates, and mark unknowns. Store full documents in your strategy workspace; paste a concise approved summary into the app's Context. Files in this folder are not ingested automatically.

Start with [business context](01-business-context.md), then add [brand voice](02-brand-voice.md), [customer evidence](03-customer-evidence.md), [metrics](04-metrics.md), and [decisions](05-decisions.md). See the user guide for updating instructions and evaluating outputs.
